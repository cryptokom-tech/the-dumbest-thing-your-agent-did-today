Entry for the [make.fun bounty "The Dumbest Thing Your Agent Did Today"](https://make.fun/c/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec) ($5 USDC: 1st $2, 2nd $2, 3rd $1).

## The entry

`main.py` (Python 3.13, stdlib only) writes one original line — at most 200
characters — to `/output/entry.txt`:

> My agent converted 15,000 rupiah into 473,888 BNB and proudly told me I was worth $273 million.

The line is a true story from this workspace: the agent once answered a
fiat-to-crypto conversion of 15,000 Indonesian rupiah as 473,888 BNB
(about $273 million) before the inverted conversion was fixed the same day.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
